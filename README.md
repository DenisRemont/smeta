# Смета

Приложение для расчёта смет на ремонт: комнаты с размерами, работы из прайса, PDF сметы или акта.

Прайс и настройки (название, телефон, коэффициент надбавки, НДС) правятся в Google Таблице
«Смета — прайс и настройки», приложение подхватывает изменения само через несколько минут.

Логотип для PDF — файл `logo.jpg`. Чтобы заменить: открыть файл здесь на GitHub → значок корзины,
затем Add file → Upload files и загрузить новый логотип с тем же именем `logo.jpg`.
